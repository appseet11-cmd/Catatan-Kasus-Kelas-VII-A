📌 Aturan Sistem — Satu Laporan PDF per Siswa + Arsip Otomatis:

  • Setiap siswa (berdasarkan NIS/NISN) hanya memiliki SATU file PDF rekap yang berisi seluruh kasusnya.
  • NIS dan NISN: Diisi terpisah. NIS/NISN sebagai kunci unik untuk mengidentifikasi siswa.
  • Nama Siswa & Orang Tua: Menggunakan data yang PERTAMA KALI diinput.
  • Baris: Gunakan tombol (+) untuk menambah baris, (-) untuk menghapus baris terakhir, dan 🔄 untuk mereset semua isian tabel.
  • Kelas: Pilih kelas siswa dari menu dropdown (VII-A s.d. VII-J).
  • 💾 Simpan ke Spreadsheet: Data akan terakumulasi. Reset tabel TIDAK menghapus data di Spreadsheet.
  • 🔑 Password Guru BK: Bisa diedit langsung di Spreadsheet → sheet "Pengaturan" → baris "passwordGuruBK" → edit kolom B.
  • 🖼️ Logo: Upload logo sekali via panel Guru BK → logo tersimpan permanen di Spreadsheet & otomatis dipakai setiap generate PDF.
  • 🏠 Tombol Kembali: Gunakan tombol "🏠 Kembali" di toolbar untuk kembali ke halaman induk.
